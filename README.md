# APP_FRANKIE

Aplicación móvil desarrollada en Flutter como proyecto de aprendizaje,
explorando las funcionalidades del framework y sus herramientas.

## Tecnologias utilizadas

- Flutter / Dart
- Firebase Core
- Cloud Firestore
- Syncfusion Flutter Calendar
- Flutter Map
- Geolocator

## Temas practicados

- Navegacion entre pantallas
- Integracion con Firebase y Firestore
- Calendario interactivo
- Mapas y geolocalización
- Selector de colores
- Manejo de coordenadas geograficas
- Estructura de proyectos en Flutter
- Manejo de widgets

## Estructura del proyecto

~~~
lib/
├── App/
│   └── app.dart          # Configuracion principal de la app
├── Navegador/
│   └── navegador.dart    # Navegacion entre pantallas
├── Pantallas/
│   ├── calculadora.dart  # Pantalla de calculadora
│   ├── calendario.dart   # Pantalla de calendario interactivo
│   ├── correo.dart       # Pantalla de correo / formulario
│   ├── principal.dart    # Pantalla de inicio
│   └── ubicacion.dart    # Pantalla de mapa y geolocalizacion
└── main.dart             # Punto de entrada de la aplicacion
~~~

## Notas

Proyecto desarrollado con fines educativos.
Firebase no esta incluido en el repositorio,
se requiere configuracion propia para correr el proyecto.
