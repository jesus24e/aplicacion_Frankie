# APP_FRANKIE

Aplicación móvil desarrollada en Flutter como proyecto de aprendizaje,
explorando las funcionalidades del framework y sus herramientas.

## Tecnologias utilizadas

- Flutter / Dart
- Firebase Core
- Cloud Firestore
- Syncfusion Flutter Calendar
- Flutter Map
- Geolocator

## Temas practicados

- Navegacion entre pantallas
- Integracion con Firebase y Firestore
- Calendario interactivo
- Mapas y geolocalización
- Selector de colores
- Manejo de coordenadas geograficas
- Estructura de proyectos en Flutter
- Manejo de widgets

## Notas

Proyecto desarrollado con fines educativos.
Firebase no esta incluido en el repositorio,
se requiere configuracion propia para correr el proyecto.
